Orbit, A Fancy Planner

Started 2025 · November origin · iOS + web

I have never experienced a day as a vertical list. Orbit started as an attempt to make time look more like it feels: circular, finite, and constantly being rearranged.

A circular 24-hour planner for visual time blocking, recurring routines, templates, and drag-based daily scheduling.

iOS App Store Web App Read More GitHub (Private)
Why I Made This

I built Orbit because traditional planners never worked particularly well for my ADHD or the way I actually schedule my life.

A lot of tasks do not happen on a strict weekly cadence. Instead, they need to happen five days after I last did them or two weeks from completion. Orbit's regenerating task system was built around that idea and remains my favorite feature.

I also wanted a better way to see where my time is actually going throughout the day instead of constantly jumping between calendars and task lists.

Time Since Chore Manager

Started December 2024 · iOS + web

Some routines should reset from the last time they were done. I do not change my sheets every Tuesday—I change them a certain amount of time after I last changed them. A surprising number of routines work this way.

Track chores, maintenance, routines, sessions, and life events by elapsed time rather than fixed calendar recurrences.

iOS App Store Web App Read More Project Notes GitHub (Private)
Why I Made This

I built this because many recurring tasks do not fit a normal weekly calendar.

Replacing HVAC filters, changing sheets, cleaning litterboxes, watering plants, fasting sessions, and dozens of other routines are often better tracked from the last completion date rather than from a fixed schedule.

Time Since supports occurrence trackers, session trackers, counters, reminders, CSV import/export, and flexible elapsed-time views ranging from days to years.

Time Here, Time There

Started 2021 · Ongoing timezone coordination

I kept opening world clocks and then doing the time-zone math myself anyway. This puts every city on one movable timeline so the overlap is visible.

A world clock built around one shared timeline: drag it and every city moves together. Daylight bands, sunrise and sunset, timezone grouping, any city as home, and an iOS home-screen widget.

iOS App Store Web App Read More GitHub (Private)
Why I Made This

I wanted a quick way to compare home time, meeting time, and destination time without juggling multiple clock apps.

The app is designed around real scheduling questions: what time is reasonable there, what does that mean here, and which cities can overlap without making someone miserable?

Catflakes

Started 2018 · Java to iOS

When I was learning to code, I challenged myself to recreate a cat-snowflake meme in Java. That was the entire idea. Years later, I rebuilt it for the App Store because apparently I remained committed to the premise.

A playful iOS and web app for falling radial cat snowflakes with wind, density, speed, and built-in cat controls.

iOS App Store Web App Project Notes GitHub (Private)
Why I Made This

Just because!

The proof of concept uses plain HTML, CSS, and Canvas instead of a heavier framework.

It currently supports four built-in cats, selectable cat types, wind drift, density controls, speed controls, and falling animation.

Passport Buddy

Started January 2020 · Ongoing travel planning

Group travel gets complicated fast when friends hold different passports. I started with a giant spreadsheet; eventually the spreadsheet became an argument for building an app.

Group travel planning by passport, visa friction, and departure airport, with destination comparisons and shared trip shortlists. Schengen itinerary checks and meeting-airport optimization remain goals.

Web App Project Notes GitHub (Private)
Why I Made This

Many of my friends from college hold different passports, which makes group travel surprisingly complicated.

I originally tracked visa requirements, passport restrictions, and travel eligibility in a giant spreadsheet. Eventually it became obvious that what I really needed was an app.

Passport Buddy helps answer a simple question: where can all of us go together in a way that is practical and affordable?

Prototype

Better NYC Map

Route planner · Prototype · Supabase

Route planners regularly suggest trips that are technically faster and obviously worse. I wanted one that understood when I would rather walk farther, avoid a transfer, or take the ferry because the ferry is nicer.

A NYC transit-map prototype for walking, transfer, and mode tradeoffs, with preview routing and an optional live routing integration.

Web App Project Notes GitHub (Private)
Why I Made This

I wanted a transit planner that reflects how people actually make NYC routing decisions, not just the mathematically shortest trip.

The project is designed around options like walking farther to avoid a transfer, preferring above-ground routes, mixing subways with buses or ferries, and comparing best-case versus worst-case transfer-heavy trips.

Longer-term, it can support native app packaging, service-alert-aware routing, accessibility preferences, and better multi-modal planning across NYC and regional transit.

Rent Stabilized Map

NYC housing · Data mapping · Research tool

Looking for a rent-stabilized apartment meant checking public records one building at a time. I wanted the useful parts on a map.

A mapping and research project for understanding rent-stabilized housing signals, building records, and neighborhood-level search tradeoffs.

Web App Project Notes
Goals

Make public housing data easier to scan during apartment research.

Help compare buildings, neighborhoods, and listing signals without treating any single dataset as definitive legal advice.

Keep the public portfolio version focused on product goals and data approach rather than linking the live project.

Paused

Pet Sticker Maker

Computer vision · Paused · Stickers

Catflakes needed isolated cat heads. I did not want to cut them out manually forever, so this became its own computer-vision project.

A utility that turns pet photos into transparent sticker assets for reuse in other apps.

Web App Security Review Project Notes GitHub (Private)
Why I Made This

I built this as an asset-generation component for Catflakes.

The goal is to let users turn their own cat photos into reusable sticker pieces without manually cutting out heads, removing backgrounds, or preparing transparent PNGs.

This project is currently paused while the Catflakes renderer is stabilized and support for bundled custom PNG and SVG assets is prioritized.
